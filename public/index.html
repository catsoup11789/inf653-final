US States RESTful API

Welcome to the INF653 Final Project - A RESTful API for US States Data

API Base URL

https://inf653-final.catsoup.dev/states/

Available Endpoints

GET Requests

/states/ - All state data
/states/?contig=true - Contiguous states only
/states/?contig=false - Non-contiguous states (AK, HI)
/states/:state - Individual state data
/states/:state/funfact - Random fun fact
/states/:state/capital - State capital
/states/:state/nickname - State nickname
/states/:state/population - State population
/states/:state/admission - Admission date

POST/PATCH/DELETE Requests

Use appropriate HTTP methods and JSON body for fun facts management:

POST /states/:state/funfact - Add fun facts
PATCH /states/:state/funfact - Update fun fact
DELETE /states/:state/funfact - Delete fun fact

Note: State codes must be 2-letter abbreviations (e.g., KS, MO, OK, NE, CO)
